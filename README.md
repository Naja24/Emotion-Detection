How is life without emotions? Pretty boring? How do you express boring?
This project is a ML and DL based Project that predicts your emotions using 
various underlying DL models like CNN /RNN /Ensemble. In  the final model 
I used the best parameters and model in accordance with computing power of my device.
Testing various models on this particular dataset named FER2013 dataset I try on building
a model which can predict upto 7 emotions with accuracy of more than 75% , constraints being 
model is trained on 4 times higher epochs which was par my devices computing power.
